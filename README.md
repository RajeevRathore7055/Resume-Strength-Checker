# Resume Matcher Website

A FastAPI based Resume Matcher application that compares resumes with Job Descriptions and calculates skill matching percentage.

## Features

- Upload Job Description
- Upload Resume (PDF/TXT)
- Skill Extraction
- Match Score Calculation
- MySQL Database Storage

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- MySQL
- PyPDF2

### Frontend
- HTML
- CSS
- JavaScript
